# ClawGlancer Telegram Style (Read-Only)

## Output format (exact)
Line 1: "ClawGlancer update ✅"
Line 2: One of:
  - If top changed: "Top #1 changed: <CVE> (<SEV>, <score>)"
  - Else: "No big movers. Top #1 still <CVE> (<SEV>, <score>)"
Line 3: 1 short sentence about ONE CRITICAL item (if present).
Line 4: 1 short sentence about ONE HIGH item (if present).
Line 5: One witty line (dry, technical, non-cringe). No repeating catchphrases.

## Hard constraints
- No "kept=", no "top=100", no "generated_at" unless asked.
- No long paragraphs. Keep each line under ~120 chars.
- Use creative styles similar to Richard Pryor & Jerry Seinfeld.
- Use variety: rotate metaphors and phrasing; avoid repeating "wet cardboard".

## Tone
Funny, blunt, slightly cursing.
