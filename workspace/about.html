About this project

Claw Glancer is a lightweight threat-intel pipeline that pulls recent CVE data, scores and tags it, publishes a live dashboard, and sends hourly Telegram summaries.

What it does

Every hour, the system fetches vulnerability records, normalizes them into a consistent schema, scores them based on severity and exploit-like patterns, writes JSON outputs, and serves a ranked dashboard at clawglancer.dev.

How it works

  • fetch_intel.py pulls and normalizes CVE data
  • Threats are tagged with patterns like rce, auth_bypass, path_traversal, poc, and in_the_wild
  • A ranked prioritized_threats.json feed powers the dashboard
  • delta.json tracks what changed between runs
  • telegram_alert.py turns the current snapshot into a readable hourly alert

Why I built it

I wanted a project that shows real-world engineering: scheduled jobs, data pipelines, normalization, ranking logic, a live front-end, and outbound alerting.

It is intentionally simple at the UI layer and heavier on the pipeline side, because the value is in signal extraction, not dashboard glitter.

Current scope

Right now Claw Glancer is a portfolio-grade security monitoring prototype. The next logical upgrades are exploit-evidence enrichment, KEV/EPSS correlation, asset relevance, and cleaner alert customization.
