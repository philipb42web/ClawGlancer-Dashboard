About Claw Glancer

A high-signal, lightweight vulnerability intelligence dashboard designed for security teams and engineers.

What It Does

Claw Glancer pulls newly published and modified vulnerability records from NIST's National Vulnerability Database (NVD). Instead of burying security analysts in hundreds of low-impact alerts, it normalizes the data into a strict schema, extracts kill-chain indicators, and computes a composite Intel Score.

How It Works

  • Scraper & Normalizer: Ingests NVD CVE 2.0 API data scoped to the recent 72-hour window.
  • Pattern Matching: Scans summaries and reference advisories for critical exploit patterns (RCE, bypass, active exploitation, PoCs).
  • Signal Extraction: Deduplicates records, discards low-severity noise (CVSS < 7.0), and produces atomic JSON artifacts.
  • Zero-Server Architecture: The dashboard runs as a pure static web application hosted on GitHub Pages with automated cron workflows.

Design Philosophy

Many vulnerability trackers are cluttered with bloated dashboards and opaque metrics. Claw Glancer prioritizes:

  • Speed: Instant client-side filtering by score, tags, vendor, and keywords.
  • Explainability: Every score is transparently backed by explicit reasons (e.g. rce+30, in_the_wild+35).
  • Minimal Attack Surface: Static client delivery without complex backend servers or database maintenance.

Roadmap

Future planned upgrades include CISA KEV cross-referencing, EPSS (Exploit Prediction Scoring System) integration, and RSS / JSON feeds for direct SIEM ingestion.
